# BoardEject v0.0.5: Archive Explorer

Your archived board should remain useful without Freeform installed.

Open [Archive Explorer](https://boardeject.dev/open), choose a `.boardejectarchive`, and inspect it locally.

- Verify file integrity and see missing or corrupted originals.
- Browse original assets with image thumbnails and supported media previews.
- Download an original file or a ZIP of all preserved originals, without changing their bytes.
- Access a board preview or editable Excalidraw file when one is already included.
- Use a desktop or mobile browser, without the Mac helper. Inspection works offline after the page loads until it is closed or refreshed.

The existing Freeform export and archive-creation workflows remain available. Archive format version 1 and existing helper downloads remain compatible.

## Boundaries

Browser input, expanded archives and bulk extraction are limited to 256 MiB; archives may contain at most 10,000 entries. Larger archives can still be verified with the Mac helper. Missing originals cannot be recovered. Media playback depends on browser codecs; PDF preview availability varies by browser.

SHA-256 verifies integrity against the enclosed manifest, not authorship. Restore/write-back is not supported. Native database records are not reconstructed into an unverified clipboard payload or editable export. Freeform compatibility and iPad ink limitations are unchanged.

Everything stays on your device. No board uploads, account or cloud storage.

Validation includes 193 automated tests, all 69 genuine capture browser regressions, fresh macOS Freeform archive creation, byte-for-byte extracted asset checks, and desktop/mobile browser checks.
