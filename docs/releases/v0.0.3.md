# BoardEject v0.0.3: Local Freeform Backup / Archive

BoardEject can now discover boards in the exact verified Freeform 4.5 database
schema and preserve one selected board as a portable `.boardejectarchive`.

The archive contains selected-board-only native records, verified metadata,
original referenced image, PDF, video and generic file bytes, plus deterministic
SHA-256 manifests. Byte-identical assets are deduplicated safely. Verification
works independently without Freeform and detects missing, corrupted, tampered or
unsafe archive content.

The macOS helper creates a stable database, WAL and SHM snapshot without opening
or modifying the live Freeform store. It queries only the verified copy in
read-only mode. Unknown schema versions and fingerprints fail closed.

Usage:

```sh
npm run archive:freeform -- scan
npm run archive:freeform -- create BOARD_UUID Board.boardejectarchive
npm run archive:freeform -- verify Board.boardejectarchive
```

Everything stays local. BoardEject does not upload boards, archives or assets.

Limitations: restore/write-back and iCloud manipulation are not supported. Only
the exact verified Freeform schema is accepted. Database-native records are not
reconstructed into an unverified clipboard payload, so the current archive path
does not produce an Excalidraw export. Editable export remains a separate,
fixture-backed clipboard workflow.
