# BoardEject v0.0.1: First public release

BoardEject converts supported Apple Freeform clipboard content into editable
Excalidraw files instead of flattened PDF/image exports.

This is an early, limited-scope release. **Current version-7 native boards,
including Freeform 4.5 captures, are still rejected.** This is not a promise
that every board from current Freeform will import.

## What works

- Editable Excalidraw output, downloads and embedded editing, with browser-tested
  shape movement, following bound arrows and text edits.
- Conservative conversion of supported decoded shapes, plain text, connector
  bindings, identity group membership, PNG/JPEG inputs and ink centerlines.
- Conversion reports and unsupported-version checks instead of fabricated output.
- Swift clipboard helper and a synthetic example to try without a Mac.
- 50 regression tests, real Freeform captures and Apple spline endpoint references.

Native evidence and decoded-model tests are distinguished in the
[support matrix](https://github.com/royalpinto007/boardeject#support-matrix).
The demo proves editable output, not complete native import.

## Known limitations

- [Native table geometry is incomplete](https://github.com/royalpinto007/boardeject/issues/12).
- [Pressure-sensitive and erased ink is unverified](https://github.com/royalpinto007/boardeject/issues/13).
- [Nonidentity groups](https://github.com/royalpinto007/boardeject/issues/8),
  [native text/connectors](https://github.com/royalpinto007/boardeject/issues/9),
  [native assets/rich text](https://github.com/royalpinto007/boardeject/issues/14)
  and [version compatibility](https://github.com/royalpinto007/boardeject/issues/6)
  need more work. Capturing records is not proof of faithful conversion.

## Try it

Visit [boardeject.dev](https://boardeject.dev), select **Try example board**, then
**Open in Excalidraw** or download the output. Real captures require the
[macOS helper](https://github.com/royalpinto007/boardeject/blob/main/docs/clipboard.md).
Keep your original board and inspect the report. From source: `npm ci` then
`npm run dev` on Node 22.12+.

Board processing stays on your device. No account, board uploads or cloud board
storage. Website hosting still produces request metadata; see
[privacy](https://boardeject.dev/privacy) and [terms](https://boardeject.dev/terms).

Contributions and sanitized native captures are welcome. Never submit private
boards. Read [CONTRIBUTING.md](https://github.com/royalpinto007/boardeject/blob/main/CONTRIBUTING.md).
