Current support

Useful where verified. Safe where uncertain.

BoardEject reports unsupported content instead of silently pretending every conversion is perfect.

Editable export

Fixture-backed Freeform 4.5 paths preserve supported shapes, editable text, tables, images, groups, transforms, connectors, and ink.

Some rich-text styling, shadows, table behavior, and geometry use documented editable approximations. Apple Pencil pressure and erased ink remain unverified from iPad-originated captures.

Local backup

The helper supports only the exact verified Freeform 4.5 schema. It snapshots the live store without modifying it and archives only the selected board with reachable original assets and integrity hashes.

Unknown schemas stop safely. Restore, write-back, iCloud manipulation, and unverified database-to-Excalidraw reconstruction are not supported.
