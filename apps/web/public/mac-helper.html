macOS setup

Use BoardEject with your own Freeform boards

The website cannot directly read Freeform's private clipboard formats or local database. The open-source Mac helper creates the local file that BoardEject needs. Nothing is uploaded.

Editable export

Copy a board into Excalidraw

  1. Run the capture helper on your Mac.
  2. Select everything in Freeform and copy it.
  3. Save the capture, then choose it on BoardEject.
xcrun swiftc apps/mac-helper/main.swift -o /tmp/boardeject-helper
/tmp/boardeject-helper Board.boardeject

Local backup

Back up one Freeform board

  1. Scan the verified local Freeform database.
  2. Choose a board UUID from the result.
  3. Create and independently verify the archive.
npm run archive:freeform -- scan
npm run archive:freeform -- create BOARD_UUID Board.boardejectarchive
npm run archive:freeform -- verify Board.boardejectarchive

Install once

BoardEject currently ships as source, so Node 22+, Swift, and Xcode Command Line Tools are required. 

git clone https://github.com/royalpinto007/boardeject.git
cd boardeject
npm ci

Archive compatibility is currently verified only for the documented Freeform 4.5 schema. Unknown versions stop safely. Restore into Freeform is not supported.
