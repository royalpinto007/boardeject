# Code of conduct

Be respectful, constructive and inclusive. Critique ideas and code, not people.
Harassment, discrimination, threats, sexualized conduct and publication of
private information are not accepted in project spaces.

Report concerns to royalpinto007@gmail.com. The maintainer will review reports
confidentially and may remove content, warn contributors, or restrict access
depending on severity. These expectations apply to issues, reviews, discussions
and events where someone represents this project.
